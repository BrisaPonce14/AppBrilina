# App Brilina - Registro de ventas


Aplicación de escritorio desarrollada en Java
para la gestión de ventas diarias de un local 
de accesorios para celulares.

## Funcionalidades actuales

- Carga de productos vendidos
- Registro de fecha, producto y monto
- Guardado de ventas en archivo CSV
- Visualización de ventas del día
- Cálculo automático del total diario

## Tecnologías utilizadas

- Java
- IntelliJ IDEA
- Maven
- Git & GitHub

## Estructura del proyecto

- model → Clases de datos (Venta, Producto, etc)
- logic → Lógica del negocio
- persistence → Guardado y lectura de archivos
- ui → Interfaz por consola
